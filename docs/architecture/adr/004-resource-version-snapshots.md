# ADR-004：工作区资源采用不可变发布版本，作品和任务保存快照

## 状态

Accepted

## 决策

内容类型、风格、创作模板和质量策略分别建模。资源可以有草稿、已发布、停用状态；每次发布创建不可变版本。作品创建保存资源引用，生成任务启动时复制资源 payload、资源 ID 和版本号作为快照。

## 原因

- 生成过程可能持续较长，不能因管理员编辑风格或质量门槛而改变进行中任务。
- 分立模型可以对不同资源做严格校验和生命周期控制。
- 快照让历史作品可重现，也便于审计和问题定位。

## 规则

- 系统内置资源不可删除，只能复制为工作区资源。
- 停用只阻止新作品引用，不影响历史快照。
- 资源发布、停用、复制和删除写入审计日志。
- 旧作品由 \`genre\`、\`style\` 和 \`creative_brief\` 回填兼容快照。

## 被拒绝方案

- 一个 JSON 通用配置表：灵活但缺少类型校验、权限语义和迁移边界。
- 任务每次运行动态读取当前资源：不可重现，且会造成中途行为漂移。
- 把角色/世界观 Canon 共享到工作区：会破坏作品之间的知识隔离。
