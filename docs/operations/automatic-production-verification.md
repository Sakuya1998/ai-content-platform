# 自动生产任务验收

日期：2026-10-10。

## 验证结果

- Python 全套临时 PostgreSQL 回归：755 passed、14 个环境依赖用例跳过，109.30 秒。
- Go 全套临时 Control PostgreSQL race 测试和 vet 通过；新增 11 个实际数据库编排测试及参数预检子用例。
- 六项完整跨服务用例一起执行：6 passed，106.67 秒；覆盖自动生产、手动分镜/时间线/合成、图片/语音、视频、文本/记忆与完整小说流程。
- Runtime 最终镜像的实际 FFmpeg smoke 通过，画面与音轨均为 2.0 秒；验证图片保持、裁剪、拼接、音频偏移/增益、中文字幕、PCM 和源时长越界。
- Ruff、部署检查、JSON 契约、两个 Compose 配置与文档链接通过。干净 wheel 与当前 125 个 Python 文件一致，不包含旧包和本地提示词模板。

模型响应由本地 HTTP 模拟，使用实际外部 MQ/RustFS 与 FFmpeg，Control/Runtime 使用临时数据库；未调用收费模型。

## 自动链路

两镜头分镜绑定一张已有图片，父任务只生成另一张图片和一段逐字配音，再创建 assemble 和 compose，共四个子任务。图片与语音供应商各调用一次；已有图片直接复用。

父任务创建后，测试把工作区默认模型切换到不可用端点；包括后续才创建的 assemble/compose，所有子任务继续携带最初冻结的路由版本。最终输出 2.5 秒的视频：第二镜头延长至实际 1.5 秒配音时长，并保留完整对白字幕。

公开 API 验证相同请求幂等重放、项目路径隔离，以及 viewer 可读取但不能推进任务。内部父任务完成必须等成片内容版本落库。

数据库用例覆盖 12 个并发推进者不重复创建任务、父子任务与 Outbox 原子性、重启恢复、取消结果证据、兄弟失败停止、多个审核轮次恢复、内容版本落库延迟、模型冻结、跨项目素材拒绝、中文标题与长镜头标识、不可执行参数的提前拒绝。修复了冻结快照重复哈希污染和审核命令跨轮次身份重复。

## 初始化和清理

外部 Control 数据库已应用 015；Runtime 复用现有 011 及之前迁移。当前默认目录为 22 个提示词身份、11 个工作流包、9 套策略；重复临时迁移全部跳过，种子创建/更新计数全部为零。

两个本地服务镜像已更新。临时 `agent-automatic-control`、`agent-automatic-runtime`、`agent-automatic-db` 容器与数据库数据卷已删除；外部基础设施和诊断产物保留，未部署持续业务 AI Worker。

使用与限制见 [自动生产任务](../architecture/automatic-production.md)。本阶段从已有分镜开始，自动补齐画面/对白素材并合成成片。音乐和音效供应商已接入并通过独立外部联调验收，详见[音乐与音效验收](music-sound-effects-verification.md)；真实供应商音质、转场和逐词字幕仍需后续单独验收。
