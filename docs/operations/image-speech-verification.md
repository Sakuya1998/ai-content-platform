# 图片与语音接入验收

日期：2026-10-10。

## 结果

- 隔离 PostgreSQL/pgvector 下 Python 全套：609 passed、5 个环境依赖用例跳过（67.30 秒）。
- Go 临时 Control 数据库下完整 race 测试与 vet 通过。
- Ruff、导出 JSON 契约、两个 Compose 配置及文档链接检查通过。
- 四个完整跨服务用例一起执行：4 passed（37.68 秒），覆盖图片/语音、视频、通用文本/记忆、完整小说流程。
- 实际接入外部 RocketMQ Proxy 与 RustFS，Control/Runtime 使用临时数据库，AI 响应由本地 HTTP 服务模拟；没有调用收费模型，也没有启用持续运行的业务 AI Worker。

图片/语音用例验证六条路径：OpenAI 兼容图片生成与编辑、Seedream 图片生成与编辑、OpenAI 兼容 TTS、豆包 TTS。均从 Go 注册模型、配置路由和冻结任务，经 MQ 派发，由 Runtime 归档资产/凭证和内容 IR，最后经事件回写 Go。编辑确实提交了冻结原图字节，每项供应商调用一次。

## 恢复与边界

覆盖审核拒绝的持久化、未知提交禁止重发、归档凭证恢复、输出/用量/回执不可变、租约过期和失效 fencing、跨项目资产拒绝、真实文件格式检查、流截断、字节上限、取消结果真实性和幂等用量。

数据库提交或未知状态记录失败保留人工恢复入口；最终 IR 上传时的 botocore 网络异常也不会把已生成素材变成不可恢复的失败。心跳异常停止当前执行并保留租约恢复，不误报远端取消。

## 初始化与交付

外部数据库已应用 Control013、Runtime010。新增两个提示词身份与两套策略；通用媒体评审生成新版本并更新关联包。当前内置目录为 20 个提示词身份、7 个工作流包、5 套策略，旧版本保留。

临时数据库重复统一迁移全部跳过；重复提示词/策略种子创建与更新数均为零。Go 与 Runtime 本地镜像已重建；Runtime 镜像确认新增协议、工作流和迁移可导入。干净 wheel 与当前 116 个 Python 源文件一致，不包含旧模块或本地提示词模板。

本轮 `agent-image-speech-control`、`agent-image-speech-api`、`agent-image-speech-db` 容器及临时数据库数据卷已移除。外部基础设施与诊断产物未删除。

配置与限制见 [图片与语音模型接入](../architecture/image-speech-models.md)。本轮没有验收真实画面/配音质量；音乐、音效、语音识别、声音克隆、多镜头及时间线合成仍需后续实现。
